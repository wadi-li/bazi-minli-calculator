# Ба Цзы + Минли — калькулятор

Автономный русскоязычный HTML-калькулятор традиционной китайской системы **Ба Цзы (八字, «Восемь знаков»)** и интерпретаций **Минли (命理)**.

## Онлайн-калькулятор

**[Открыть калькулятор на GitHub Pages](https://wadi-li.github.io/bazi-minli-calculator/)**

Работает непосредственно в браузере, без установки.

## Возможности

- Ввод даты, времени, пола и места рождения.
- Поиск города по первым буквам, справочник городов бывшего СССР, включая Анадырь и Билибино.
- Историческое смещение UTC по часовому поясу IANA (в пределах точности базы браузера).
- Расчёт четырёх столпов: года, месяца, дня и часа; ввод известных столпов для сверки.
- Пять элементов, скрытые стволы, десять божеств и пояснения на русском языке.
- Диаграммы и рекомендации для знакомства с традицией.

## Что такое Ба Цзы и Минли

Ба Цзы — традиционный метод китайской метафизики, связывающий год, месяц, день и час рождения с небесными стволами и земными ветвями. Минли — более широкая традиция интерпретации жизненных закономерностей. Пять элементов (У Син) и Инь/Ян используются как символический язык описания карты.

## Запуск

Откройте `index.html` в современном браузере. Сервер не требуется.

## Точность

Границы солнечных месяцев пока приближённые; исторические часовые пояса зависят от базы браузера. Для профессионального использования необходима сверка по астрономическим эфемеридам и эталонным картам. Ба Цзы и Минли не являются научно подтверждёнными методами диагностики личности или прогнозирования событий.
